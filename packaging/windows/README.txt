PYTHON DISCOVERY for Windows
============================

1. Unzip this whole folder somewhere permanent (for example Documents\Python Discovery).
   Do not run it from inside the zip.
2. Double-click "Start Python Discovery.bat".
   Windows may show "Windows protected your PC": click More info, then Run anyway.
   (The script is plain text: you can open it in Notepad and read it first.)
3. A small black window appears (leave it open, you can minimize it) and the app opens in its
   own window using Microsoft Edge, which is already on Windows 10 and 11.

Nothing is installed. Python runs inside the app (WebAssembly), so you do not need Python on Windows.
Your files and progress are saved in the browser's storage for http://localhost:4173, so always start
the app with this .bat file and keep using the same browser.

To stop the app, close the black window.

Optional: with the app open in Edge, click the "..." menu > Apps > Install this site as an app, and
Edge adds a Start-menu and desktop shortcut. The black window must still be running for it to open.

Privacy: the server only listens on this computer (localhost), and nothing is sent anywhere.
